# Versión Analisis Factorial

1.  Abra `Analisis_Factorial_Unidad2.Rmd` en RStudio.
2.  Los datos están incluidos en `datos/`.
3.  Verifique los ocho paquetes indicados en el bloque de configuración.
4.  Pulse **Knit**. La salida inicial es HTML y no requiere LaTeX.

## Controles incorporados

-   Muestra AFE y AFC separadas desde el inicio.
-   Matriz policórica con nombres preservados.
-   Depuración real y validada ítem por ítem.
-   Comparación AFE de 4, 6 y 8 factores.
-   Sintaxis AFC generada automáticamente desde cada AFE.
-   Comparación confirmatoria WLSMV entre candidatos.
-   Exclusión automática de soluciones impropias.
-   Selección final solo entre modelos admisibles.
-   CR, AVE y HTMT calculados únicamente para el modelo final admisible.
-   Sensibilidad con MLR.
-   Datos y resultados trazables.
